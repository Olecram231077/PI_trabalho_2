# Sistema Web de Gerenciamento de Professores

Sistema desenvolvido para o Projeto Integrador II (UNIVESP) — Eixo de Computação.

## Sobre o projeto

Evolução do sistema criado no PI I, agora com API REST, JavaScript assíncrono,
integração com ViaCEP, acessibilidade WCAG 2.2, testes automatizados e deploy em nuvem.

## Tecnologias

- Python 3.11 + Flask 3.0
- SQLAlchemy + PostgreSQL
- JavaScript (Fetch API) + Bootstrap 5 + Chart.js
- pytest para testes automatizados
- Gunicorn + Render para deploy
